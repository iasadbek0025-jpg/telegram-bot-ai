# 🤖 PC Controller Telegram Bot

A Python-based Telegram bot that allows you to remotely control and monitor your Windows computer through chat commands, featuring text-to-speech voice responses using `edge-tts`.

---

## ✨ Features

- **Remote Commands:** Execute system actions via Telegram messages.
- **Voice Responses:** Natural sounding Russian voice replies generated via `edge-tts`.
- **Lightweight & Fast:** Built with Python and `python-telegram-bot`.
